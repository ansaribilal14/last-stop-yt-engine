### 2.1 The Big Five for an agentic video pipeline

```text
calesthio/OpenMontage — 65,707★ · Python · AGPL-3.0
  https://github.com/calesthio/OpenMontage
  Usage: WORLD'S FIRST open-source agentic video production system. Turns any
  AI coding agent (Claude Code/Cursor/Codex/Copilot) into a full studio:
  research → proposal → script → scene_plan → assets → edit → compose, with
  12 production pipelines, 100+ tools, 700+ agent skill/knowledge files, JSON
  checkpoints (resumable + audit trail), human-approval gates, pre-compose
  validation, post-render self-review. FREE zero-key tier: Piper TTS +
  Archive.org/NASA/Wikimedia + Pexels/Unsplash/Pixabay + Remotion +
  HyperFrames + FFmpeg + word-level subtitles. Optional paid: ElevenLabs,
  Suno, Kling/Veo/Runway, FLUX. Its `documentary-montage` pipeline does
  CLIP-indexed semantic retrieval over real footage archives — the single
  best foundation for your documentary goal. Render targets: Remotion
  (default), HyperFrames, or FFmpeg; YouTube 1080p/4K profiles built in.
  ⚠ AGPL-3.0 (fine for self-use; copyleft if you redistribute modifications).

heygen-com/hyperframes — 59,500★ · TypeScript · Apache-2.0
  https://github.com/heygen-com/hyperframes  ·  https://hyperframes.heygen.com
  Usage: "Write HTML. Render video." The engine behind /brag. A video is an
  index.html with data-start/data-duration/data-track-index attributes;
  GSAP/CSS/Lottie/Three.js/Anime.js animations (must be seekable); renderer
  seeks each frame in headless Chrome via Puppeteer + FFmpeg → deterministic
  MP4. Packages: CLI, engine, producer (capture/encode/audio mix), studio,
  player, shader-transitions, aws-lambda distributed render. 21 published
  agent skills (/hyperframes router, /faceless-explainer, /embedded-captions,
  /music-to-video...), Claude Code/Codex/Cursor plugin, npx skills add.
  THE rendering engine for agent-authored 1080p video. Node 22+ & FFmpeg.

OpenCut-app/OpenCut — 93,312★ · TypeScript · MIT
  https://github.com/OpenCut-app/OpenCut  ·  https://opencut.app
  Usage: The open-source CapCut alternative (web/desktop/mobile editor).
  ⚠ Currently mid ground-up rewrite; usable legacy in opencut-app/opencut-classic.
  Roadmap promises exactly what agents need: Editor API, plugin system, Rust
  core, MCP server, headless mode (batch render), in-editor scripting — none
  shipped yet. Verdict: watch, don't build on (today it's a GUI app).

latent-spaces/brag — 14,588★ · Python/skill · MIT
  https://github.com/latent-spaces/brag
  Usage: The agent-skill blueprint. "You built it. Now brag." Turns a project
  into a short shareable launch video (music, motion, share copy) in one
  command: agent owns the story → hands a creative brief to Hyperframes →
  renders brag.mp4 (plan + composition brief + share copy in brag-output/).
  Optional --voice (Kokoro). Install: /plugin marketplace add latent-spaces/brag
  or npx skills add. NOT a documentary tool itself — it is the reference
  architecture for packaging a video-producing agent skill (this is the repo
  to copy structure from).

ChatCut-Inc/agent-plugin — 930★ · plugin (skills + MCP) · license n/a
  https://github.com/ChatCut-Inc/agent-plugin  ·  https://chatcut.io
  Usage: Official plugins connecting Codex, Claude Code, Grok, Cursor, Kimi
  to ChatCut — a web/desktop AI video editor. Agent can: import media, edit
  the timeline, create motion graphics, generate video/image/music/voice,
  transcribe, caption, export (incl. Premiere/DaVinci XML + CapCut drafts;
  Seedance 2.5/Kling 3.0 models; local 4K desktop export). MCP endpoint:
  api.chatcut.io/api/external-mcp/mcp (`claude mcp login plugin:chatcut:chatcut`).
  ⚠ Commercial SaaS — needs ChatCut account + credits (per-second billing).
  Most polished hosted MCP editing surface available.
```
